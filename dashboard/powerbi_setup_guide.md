# Power BI Dashboard Setup & Visual Blueprint Guide

This guide provides step-by-step instructions for creating the 4-Page **E-Commerce Customer Intelligence & Sales Analytics** Dashboard in Power BI Desktop.

---

## 1. Connecting Data Sources in Power BI

### Option A: Import CSV Files (Easiest & Fastest)
1. Open **Power BI Desktop**.
2. Click **Get Data** -> **Text/CSV**.
3. Import the following files from `data/processed/`:
   - `cleaned_transactions.csv`
   - `customer_features.csv`
   - `customer_segments.csv`
   - `churn_predictions.csv`
   - `forecasts.csv`
4. Click **Load**.

### Option B: Connect SQLite Database
1. Go to **Get Data** -> **More** -> **ODBC** or **SQLite**.
2. Select the database file at `data/ecommerce.db`.
3. Load tables: `transactions`, `customer_segments`, `churn_predictions`, `sales_forecasts`.

### Data Model Relationships (Model View)
Ensure the following 1-to-Many relationships are created:
- `customer_segments.CustomerID` (1) ───> `cleaned_transactions.CustomerID` (*)
- `churn_predictions.CustomerID` (1) ───> `cleaned_transactions.CustomerID` (*)

---

## 2. Page 1: Executive Overview

**Objective:** Executive C-Suite view of top-line revenue, order volumes, customer count, and sales trends.

### Visual Layout:
1. **KPI Cards (Top Banner):**
   - **Total Revenue:** `SUM(cleaned_transactions[Revenue])` (Format: Currency `$`)
   - **Total Orders:** `DISTINCTCOUNT(cleaned_transactions[TransactionID])`
   - **Total Customers:** `DISTINCTCOUNT(cleaned_transactions[CustomerID])`
   - **Average Order Value (AOV):** `AVERAGE(cleaned_transactions[Revenue])`
2. **Line & Stacked Column Chart (Center):**
   - **X-Axis:** `cleaned_transactions[TransactionDate]` (Year / Month)
   - **Y-Axis (Column):** Gross Revenue
   - **Y-Axis (Line):** Order Volume
3. **Bar Chart (Bottom Left):**
   - **Category Performance:** Revenue by `ProductCategory` (Sorted Descending)
4. **Map / Filled Map (Bottom Right):**
   - **Geographic Sales:** Revenue by `Country`

---

## 3. Page 2: Customer Intelligence (RFM & Segmentation)

**Objective:** Deep-dive into customer behavioral clusters produced by K-Means ML algorithm.

### Visual Layout:
1. **Donut Chart (Top Left):**
   - **Segment Share:** Legend = `customer_segments[CustomerSegment]`, Values = `Count of CustomerID`
   - Shows percentages (e.g., VIP 18%, Regular 41%, Occasional 27%, At-Risk 14%).
2. **Clustered Column Chart (Top Right):**
   - **Segment Revenue Contribution:** Legend/Axis = `CustomerSegment`, Value = `SUM(Monetary)`
3. **Scatter Chart (Center):**
   - **RFM Distribution:** 
     - **X-Axis:** `Recency` (Days)
     - **Y-Axis:** `Monetary` ($)
     - **Legend / Color:** `CustomerSegment`
     - **Size:** `Frequency`
4. **Data Matrix Table (Bottom):**
   - **Columns:** `CustomerSegment`, `CustomerCount`, `AvgRecency`, `AvgFrequency`, `AvgMonetarySpend`

---

## 4. Page 3: Predictive Analytics (Churn ML & Revenue Forecast)

**Objective:** Proactive risk management and future revenue trajectory.

### Visual Layout:
1. **Churn Risk KPI Cards (Top Banner):**
   - **High-Risk Customers:** `COUNT(churn_predictions[CustomerID])` where `RiskCategory = "High Risk"`
   - **Revenue Exposure at Risk:** `SUM(churn_predictions[Monetary])` where `RiskCategory = "High Risk"`
2. **Bar Chart (Top Right):**
   - **Customer Distribution by Risk Level:** Axis = `RiskCategory`, Values = `Count of CustomerID` (Colors: Red for High Risk, Yellow for Medium, Green for Low)
3. **Line Chart with Confidence Bounds (Bottom):**
   - **X-Axis:** `forecasts[Date]`
   - **Y-Axis:** `ActualRevenue` (Historical) and `PredictedRevenue` (Forecast)
   - **Secondary / Band:** `LowerBound` & `UpperBound`
   - Add a vertical reference line separating Historical vs Forecast data.

---

## 5. Page 4: AI Business Insights & Campaign Generator

**Objective:** AI-generated executive strategy and automated campaign preview.

### Visual Layout:
1. **HTML / Markdown Card Visual (Left Half):**
   - Display content of `outputs/reports/executive_summary.md`.
   - Shows AI-generated Executive Summary, Churn Exposure Analysis, and 4 Management Recommendations.
2. **Interactive Segment Slicer (Top Right):**
   - Slicer visual on `customer_segments[CustomerSegment]`.
3. **Campaign Copy Preview Card (Bottom Right):**
   - Displays segment-targeted marketing email subject, body, and incentive generated by `campaign_generator.py`.
